## Combination Rankings

| Rank | Combination | Example | Beats |
|------|-------------|---------|-------|
| 1 | **Larger Combination** | 3-card Run (2-3-4) | Any 2-card combination |
| 2 | **Set (equal count)** | Pair (7-7) | Run of 2 (8-9) |
| 3 | **Higher Set** | Pair (9-9) | Pair (8-8) |
| 4 | **Higher Run** | Run (4-5-6) | Run (3-4-5) |
| 5 | **Higher Single** | Single (8) | Single (7) |
